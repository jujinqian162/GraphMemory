\section{实验}

\subsection{实验设置}

\paragraph{研究问题。}
实验围绕三个问题展开。\emph{RQ1} 考察在固定的 top-$k$ 预算下，
显式图结构能否提高多跳证据检索的完整性。\emph{RQ2} 考察关系感知的
图编码能否在启发式图重排和任务内微调的稠密检索之上，进一步改善
证据路径恢复。\emph{RQ3} 考察执行级溯源结构能否提高模拟智能体轨迹中
完整依赖集合的恢复率，以及这种提升主要来自图消息传递、关系类型、
边权重还是困难负样本。

\paragraph{数据集与划分。}
证据路径实验使用 HotpotQA、2WikiMultiHopQA 和 MuSiQue。对于每个
数据集，我们保留其训练集，取带标签开发集的前 500 个样本进行模型
选择，并将其余开发样本留作最终测试。我们还由 2WikiMultiHopQA 构造
了一个受控的执行溯源基准：将两条可恢复的支持事实映射为带类型的
工具调用、工具输出和数据流依赖，同时加入结构相似的非 gold 分支。
该基准用于隔离执行依赖对检索的作用，但不能替代自然产生的多智能体
执行轨迹。表~\ref{tab:data} 给出各划分规模。

\paragraph{对比方法。}
在证据路径检索中，\textbf{BM25} 和 \textbf{Dense} 分别作为词法检索
和预训练稠密检索基线。\textbf{BM25-Graph} 与 \textbf{Dense-Graph}
使用固定的证据图启发式规则重排初始结果。\textbf{Dense R-GCN} 以冻结
的稠密表示作为节点特征，并通过关系图卷积网络编码证据图。
\textbf{Dense-FT} 在任务数据上微调稠密检索器；\textbf{Dense-FT R-GCN}
则使用微调后的表示初始化 R-GCN，是该任务设置下的完整模型。

在模拟轨迹实验中，\textbf{BM25}、\textbf{Dense} 和 \textbf{Dense-FT}
分别提供稀疏、预训练稠密和任务适配的稠密检索基线。
\textbf{FastGraphRAG-style} 是一个紧凑的非 LLM 实体图基线：它以
确定性方式抽取并链接实体，组合词法与稠密检索种子执行 Personalized
PageRank，再将实体分数投影回候选证据。该方法借鉴 FastGraphRAG 的
非 LLM 实体检索思想，但不是包含 LLM 社区摘要与生成阶段的完整
GraphRAG 复现。\textbf{EPGM} 在类型化执行溯源图上进行有界搜索，
将语义相关性、依赖完整性、字段绑定和 grounding 组合为路径分数，
不进行任务特定的参数训练。\textbf{EPGM R-GCN} 是其可训练的关系感知
版本：它对预训练稠密节点表示执行三层关系特定的消息传递，对
\texttt{ToolOutput} 候选排序，并联合预测逻辑上的输出间依赖边。
Dense-FT 训练 1 个 epoch；EPGM R-GCN 训练 15 个 epoch，并按开发集
Full Support@5 选择检查点；二者均使用随机种子 13。

\paragraph{评测指标。}
Recall@$k$ 衡量前 $k$ 个结果覆盖 gold evidence 的比例；Full
Support@$k$ 仅在全部 gold evidence 均进入前 $k$ 时记为 1，因此直接
衡量完整支持集合是否被找回。MRR 衡量第一个 gold evidence 的排名。
Connected Evidence Recall 衡量检索证据在诱导子图中是否保持连通；
Path Recall@10 衡量检索子图是否包含连接 gold evidence 的有效路径；
Edge Recall@10 衡量 gold dependency edge 的直接恢复比例。HotpotQA
不提供有方向的 gold dependency path，因此只报告连通性而不报告路径
与边召回。路径列中的破折号表示该方法不返回溯源子图，因而指标未定义，
而不是取值为零。为进一步区分“平均找回部分证据”和“完整找回整条
支持链”，我们还使用完整性差距
$\Delta_{\mathrm{comp}}@k=\mathrm{Recall}@k-\mathrm{Full\ Support}@k$
作为诊断量。该差距越小，表示普通召回中由只命中部分 gold evidence
造成的虚高越少；它用于解释既有指标，而不是新增的主评测指标。

移除桥接边后，Dense R-GCN 与 Dense-FT R-GCN 的 Path Recall@10

在两种编码器之间稳定复现，因此只将其视为仍需多随机种子验证的调参
选择，而不是已经独立成立的贡献。

实际观测到的检索时间，而不是严格控制硬件与缓存后的系统基准，并且不
包含数据生成、图构造和模型训练。

\subsection{执行溯源模型消融}

\paragraph{模型实现与消融定位。}
执行溯源 R-GCN 并不是在最终排序分数上附加一项手工图奖励，而是对整条
轨迹进行可学习的关系传播。每个请求首先以唯一的 Task 节点作为查询锚点，
将 Task、Agent、ToolCall 和 ToolOutput 等节点的文本分别加上 E5 的
query/passage 前缀，并编码为归一化的 768 维冻结文本表示。模型再拼接
16 维节点类型嵌入，经线性层投影到 256 维隐空间。每条原生边均展开为
forward 和 reverse 两条消息边；contains、invokes、returns、feeds 等
关系拥有独立的变换矩阵，feeds 还根据输出字段到输入参数的绑定类型细分
关系。完整模型堆叠三层 R-GCN，每条消息可写为
$w_{uv}c_{v,r}^{-1}W_r h_u$：其中 $W_r$ 由关系类型决定，$w_{uv}$
来自构图阶段的边权，$c_{v,r}$ 对同关系入度进行归一化。聚合消息与节点
自身变换相加后，依次经过 ReLU、dropout（0.1）和层归一化。这使任务语义、
工具调用层级和字段级数据流能够在同一节点状态中联合编码。

模型使用两个共享图表示但目标不同的预测头。候选头以
$[h_o,h_q,h_o\odot h_q]$ 为输入，为每个 ToolOutput 产生检索 logit；
依赖头以 $[h_s,h_t,h_s\odot h_t,h_q]$ 为输入，对候选逻辑转移打分。
逻辑转移并非任意节点对，而是将“ToolOutput$_s$ 经 feeds 进入 ToolCall，
再由 returns 到 ToolOutput$_t$”这两条原生边折叠得到，因此边监督直接
对应上游输出是否被下游调用消费。训练目标为候选二元交叉熵与带正例重权的
依赖边二元交叉熵之和，即
$\mathcal{L}=\mathcal{L}_{\mathrm{cand}}+0.5\mathcal{L}_{\mathrm{edge}}$。
完整训练使用 AdamW、$10^{-4}$ 学习率、128 的批大小、1.0 的梯度裁剪
和最多 15 个 epoch；每个正例配两个随机负例、两个 BM25 困难负例和
两个稠密困难负例。推理时先按候选头对全部 ToolOutput 排序；只有首尾
节点都进入 top-$k$ 的逻辑转移才可输出，并对同一来源仅保留边头得分最高
的后继，最后还原成原生 feeds/returns 轨迹。因此 Path@10 与 Edge@10
同时检验了候选覆盖和依赖解码，而不是脱离检索结果单独评估边分类器。

基于上述计算链，我们在相同的 74,012/500/2,851 训练、模型选择和测试
划分上运行四个有明确定位的变体。w/o graph 将图卷积层数置为零，但保留
节点类型表示、候选打分器和依赖边预测头，用于隔离消息传递；w/o edge
type 保留图连接与边权重，但以一套共享变换替代关系特定变换，用于检验
关系语义；w/o edge weight 保留邻接关系和关系标识，并将所有边权重统一
设为 1；w/o hard negatives 取消 BM25 与稠密困难负样本，仅保留随机
简单负样本。所有变体使用随机种子 13，并分别按 500 条开发样本上的 Full
Support@5 选择检查点。该组结果来自独立训练批次，因此表~\ref{tab:provenance-ablation}
只用于表内比较；完整模型与表~\ref{tab:provenance} 中主实验模型的细小
数值差异不应解释为方法变化。

\paragraph{关键指标显示图传播带来跨目标的一致收益。}
表~\ref{tab:provenance-ablation} 同时覆盖四类互补目标：Recall@2 衡量
极小预算下的早期排序，Full Support@5 衡量两个相关输出能否共同进入
上下文，Path@10 与 Edge@10 则衡量依赖结构恢复。完整模型在 Path@10
和 Edge@10 上分别达到 97.47\% 和 97.26\%，为所有变体最高；在

下结论。

传播使上游证据输出能够通过 feeds/returns 连接影响下游输出，并让查询
锚点的信息沿调用层级到达候选节点；这正是两个 gold 输出能够被联合前置
到小预算中的原因。

将关系特定变换改为共享变换也使 Recall@2 和 Full Support@5 分别下降
7.42 和 3.86 个百分点，路径与边召回分别下降 1.44 和 1.54 个百分点；
对应地，top-5 完整轨迹减少 110 条，top-10 未完整轨迹由 24 条增加到
58 条。该变体保留完全相同的邻接关系、传播层数与边权，差异只来自
$W_r$ 是否按关系区分，因此它比“去掉整张图”更精确地说明了类型化传播
的独立作用。实验表明，调用层级边和字段数据流边携带的方向与语义并非
可以由一套无类型变换充分替代；尤其是在早期排序阶段，关系类型有助于
把结构相邻但功能不同的 Agent、ToolCall 与 ToolOutput 消息区分开来。

边权重的证据更为细致。将边权统一后，Full Support@5 和 Full
Support@10 分别小幅提高 0.18 和 0.11 个百分点，在 2,851 个测试样本
上只对应多完整覆盖 5 个和 3 个样本；与此同时，MRR、Path Recall@10
和 Edge Recall@10 分别下降 3.65、1.51 和 2.00 个百分点。因此，当前
结果可以部分证明边权有助于首个相关输出的排序和依赖恢复，但它对
top-$k$ 完整支持率的作用在当前划分上接近中性。这种差异与实现机制一致：
边权直接缩放传播消息，容易改变候选之间的细粒度次序和依赖边分数；只要
两个 gold 输出仍落在同一个 top-$k$ 集合中，Full Support 就不会随内部
排序变化。取消困难负样本后，平面排序指标最多提高 0.14 个百分点，而
路径与边召回分别下降 0.32 和 0.46 个百分点。因而，当前实验更适合将
困难负样本解释为辅助训练策略：它对结构恢复可能有小幅帮助，但单种子
结果只显示出较弱且方向不完全一致的独立贡献。

\paragraph{残余错误指向第二跳覆盖，而不是无差别扩大子图。}
完整模型的 24 条残余失败全部得到保存，其中 22 条已经找回两个 gold
输出中的一个，只缺少另一个；仅 2 条同时遗漏两个输出。因此，完整模型
剩余错误主要是“近完成但缺一跳”，后续改进应优先提升第二条依赖输出的
种子覆盖与联合排序，而不是单纯扩大返回子图。由于依赖边只有在两个端点
都进入 top-10 后才参与解码，这 22 条单端点遗漏也解释了为何候选召回的
小幅变化会同时反映到 Path@10 与 Edge@10 上。

输出密度进一步排除了“多输出边即可提高边召回”的替代解释：w/o edge
weight 和 w/o hard negatives 平均返回 9.15 和 9.03 条边，均多于完整
模型的 8.91 条，但 Edge Recall@10 反而更低。完整模型以更少的平均边数
达到更高边召回，说明关系变换和边权主要提高了依赖选择质量，而不是让
解码器无差别连接更多候选。需要注意的是，当前解码器对每个来源最多保留
一个后继，这与本合成基准的二跳链结构匹配；在允许一个输出被多个调用消费
的真实轨迹上，还需要检验多分支解码和边精确率。

综合主表、组件指标、开发集选择和失败分解，可以得到清晰的组件层级：图
消息传递是早期排序、完整支持和依赖恢复的主要来源；关系特定变换提供第二
层稳定增益；边权对 MRR、路径与边恢复具有可观但指标相关的帮助；困难负
样本在当前配置中贡献较小，更适合作为辅助训练策略。该层级与模型的实际
计算路径一一对应，也避免把接近满分的总体结果笼统归因于“使用了图”。

\subsection{局限性与稳健性}

现有实验已经可以从受控检索、完整证据恢复和依赖结构重建三个层面，部分
证明结构化执行溯源记忆的有效性；其证据范围目前主要集中在检索阶段，
对完整多智能体记忆生命周期只能提供部分支持。第一，合成执行溯源基准
由带标签的问答证据链确定性转换而来，而不是从异构、自然产生的智能体
日志中采集。转换过程还利用 supporting-fact 信息，在语义图构造遗漏
连接时保证 gold transition 仍然可恢复。因此，EPGM R-GCN 的近满分
结果直接说明模型能够在受控、标签派生的执行拓扑上恢复相关输出与依赖，
但对独立构造的真实智能体轨迹泛化能力只能提供有限的间接证据。未来在
包含工具失败、重试、并行分支、证据修订和跨智能体交接的自然日志上复现
同一优势，将显著扩展这一结论的适用范围。

第二，所有结果都来自一个固定划分和一个训练随机种子，目前未报告多种子
方差或 bootstrap 置信区间。去除边权和困难负样本后出现的零点几个百分点
反向提升，说明这些小效应需要更多重复实验才能确定方向；相对而言，去除
图传播造成 16.98--36.48 个百分点的跨指标下降，并同时出现在开发集、
测试集和失败数量中，因而是当前更稳健的结论。第三，当前实验评估检索、
完整支持和路径恢复，因此可以部分支撑“结构化记忆能够为下游推理提供更
完整依据”这一主张；对“减少无依据声明”或“提高下游影响追踪准确率”等
系统级效果仍只能提供间接支持，尚需把检索结果接入真实决策或生成任务。
路径与边指标目前也以召回率为主，后续加入边精确率、F1 和分支级完整率，
可以更全面地量化过度预测与多分支恢复。

第四，w/o graph 只移除了图消息传递，仍保留节点类型嵌入、候选打分器、
由图结构枚举出的逻辑 transition 以及依赖边预测头，因此它回答的是
“传播是否必要”，而不是“图模型相对完全平面模型的全部差异”。主实验中
独立的 Dense-FT 已提供平面文本基线；若要进一步定位每一项结构信息，
后续还应分别移除节点类型、字段绑定特征和边预测损失，打乱数据流关系，
并在包含真实证据修订事件的轨迹上检验失效惩罚。综上，当前结果可以作为
执行溯源检索、关系消息传递和依赖恢复有效性的直接证据，并为完整多智能体
记忆系统提供部分实验支持；更广泛的系统级结论可由多种子重复、自然轨迹
和端到端任务继续补强。
